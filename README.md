# NutriGestor CRM

Sistema de gestão comercial para equipes de representantes em nutrição animal.

O NutriGestor CRM foi desenvolvido para transformar equipes comerciais em operações orientadas por dados, planejamento, indicadores e inteligência comercial.

---

## Principais Funcionalidades

### Gestão Comercial
- Gestão de representantes
- Gestão de clientes
- Pipeline de oportunidades
- Gestão de metas
- Registro de atividades e visitas
- Histórico comercial

### Inteligência Comercial
- Dashboard executivo
- Analytics avançada
- Forecast comercial
- Curva ABC
- KPIs regionais
- Alertas inteligentes

### Inteligência Artificial
- IA Insights
- Recomendações comerciais
- Importação inteligente de Excel
- Análises preditivas
- Automação de processos

### Aplicativo de Campo
- Registro rápido mobile
- Relatórios diários
- QR Code de acesso
- Compartilhamento via WhatsApp

## Objetivo

- orientado por dados;
- baseado em planejamento;
- suportado por inteligência artificial;
- escalável e auditável.
